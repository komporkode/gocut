Kompilasi Mandiri untuk macOS dan Linux

Arsip biner macOS universal dan AppImage Linux untuk v0.8.0/v0.9.0-beta belum diterbitkan di GitHub Releases. Anda dapat membangun binary asli langsung dari kode sumber memakai Go, Node.js, Wails v2, dan FFmpeg lokal.

Kebutuhan Sistem: Go 1.23+, Node.js 20+, Wails CLI v2, FFmpeg & FFprobe di PATH 
git clone https://github.com/komporkode/gocut.git
cd gocut
npm ci
wails build -clean

Untuk macOS universal, lihat alur kompilasi di berkas .github/workflows/release.yml.

Dirancang untuk Editing Lokal Tanpa Menguras Ruang Drive C:

01 / WORKSPACE & STORAGE

Penyimpanan Drive Mandiri & Whisper AI Luring

Pilih lokasi penyimpanan proyek dan cache render di drive pilihan Anda (misalnya D:\GoCut\data\) dengan opsi pemindahan data satu klik. Mode portabel berjalan mandiri dari folder instalasi tanpa menulis ke registry Windows atau %APPDATA%.

  • Server streaming HTTP 206 byte-range internal untuk scrubbing cepat tanpa lag.
  • Transkripsi suara ke teks via C++ whisper.cpp luring (tiny 75 MB, base 145 MB, small 480 MB) serta impor file .bin GGML sendiri.
  • Pemulihan autosave proyek tervalidasi skema v1 agar file proyek lama tetap terbaca utuh.
02 / COMPOSITOR & EXPORT ENGINE

Efek Film Grain 60 FPS & 6 Preset Ekspor Sekali Klik

Pratinjau Canvas 60 FPS di GoCut v0.9.0-beta memanfaatkan Lookup Table pra-komputasi (SIN_LUMA_LUT 256 entri dan NOISE_TABLE 4096 entri) bebas alokasi GC sehingga tekstur butiran film tetap mulus sekaligus identik saat dirender ke FFmpeg.

  • 8 emulsi Film Grain (Kodak 35mm, Fuji Eterna, 16mm Analog, Super 8mm, CRT/VHS) plus Gaussian, Motion, dan Radial Blur.
  • 7 Layer Blend Modes (Screen, Multiply, Overlay, Soft/Hard Light, Color Dodge) dan klip Adjustment Layer multi-lapisan.
  • 6 preset ekspor sekali klik (YouTube 4K, 1080p, TikTok/Reels, H.265 Hemat, WhatsApp/Web, Audio Only MP3/WAV) dengan deteksi NVENC, QSV, dan AMF.

Catatan Rilis

2026-11-05 · Pro Effects, Compositing & Export Suite
  • Film Grain & Sensor Texture Suite: 8 preset emulsi dengan kurva proteksi sorotan sin(L*pi) dan dispersi RGB.
  • Suite Blur (Gaussian, Motion 360 derajat, Radial) dan Stylize (Vignette, Chromatic Aberration, Scanlines, Bloom, Sharpen).
  • Adjustment Layer terpadu dan 7 Layer Blend Modes dengan paritas pratinjau Canvas terhadap filter blend FFmpeg.
  • Copy/Paste Attributes (Ctrl+Alt+C / V), Timeline Markers (M), Track Solo (S), serta 6 preset ekspor 1-klik dengan NVENC/QSV/AMF.
  • Keamanan: sanitasi path traversal pada SaveMediaCache dan deduplikasi kontrol ProEffectsControls.
2026-11-01 · Storage Isolation, Whisper AI & Dual Installer
  • Custom Drive Storage (<Drive>:\GoCut\data\) dengan deteksi mode portabel otomatis dan fitur RelocateStorage 1-klik.
  • WhisperManager C++ untuk model GGML tiny (~75 MB), base (~145 MB), small (~480 MB) dan impor file .bin offline.
  • Dual installer Windows: GoCut-Setup-x64.exe (Inno Setup 6) dan GoCut-WebSetup.exe (< 3 MB berbasis Go).
  • Perbaikan validasi pemulihan proyek v1 serta pesan kesalahan lokal berbahasa Indonesia yang jelas.
2026-10-26 · Creative Suite, Compound Timeline & Audio Separation
  • Separate Audio & Recover Audio untuk memisahkan audio dari klip video sambil mempertahankan penautan linkId.
  • Compound Clips & Sub-Timeline bersarang dengan navigasi breadcrumb dan pratinjau real-time.
  • Drag-and-drop aset bawaan, kontrol transport 3-kolom presisi tengah, serta sinkronisasi 4 bahasa (ID, EN, ZH-CN, TR).

Xiangyu-CAS & ReaCut contributors (Copyright (c) 2026 ReaCut contributors)

GoCut adalah fork independen dari ReaCut. Model proyek JSON tervalidasi, mesin evaluasi keyframe, compositing kanvas, editor timeline multi-trek, 64 aset bawaan orisinal, dan dasar interoperabilitas draf CapCut berasal dari basis kode MIT ReaCut yang kemudian diporting dari Electron ke Go + Wails.

morluto

github.com/morluto/rea

Komponen Terbuka & Jaminan Privasi

  • Go 1.23+ & Wails v2 Menjembatani backend asli dan jendela WebView2 sistem tanpa membundel Chromium terpisah.
  • FFmpeg & FFprobe (Eksternal Lokal) Pemeriksaan media dan render ekspor dilakukan melalui argumen proses aman tanpa shell injection.
  • whisper.cpp (GGML) & React 19 + Zustand + Vite Transkripsi luring lokal (model GGML base opsional) dan antarmuka reaktif. Font Noto Sans SC (SIL OFL 1.1) dan ikon Lucide (ISC).
  • SignPath Foundation & Privasi Tanpa Cloud Penandatanganan kode sumber terbuka gratis didukung oleh SignPath Foundation (signpath.org). Zero telemetri, media tetap di perangkat Anda.
